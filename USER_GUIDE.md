# User Guide - Copy Buttons & Theme Switching

## Copy Button - What's New

### Visual Changes
The copy buttons that appear on code blocks in AI responses now have a modern, polished look:

```
Before: [Copy]           Simple flat button
After:  [Copy]           Elevated button with gradient
        ↓ gradient         Smooth hover effect
        ↓ hover effect     Better visual feedback
```

### How Copy Buttons Work

1. **Hover State** 
   - Button elevates slightly (translateY)
   - Background becomes more prominent
   - Soft shadow appears
   - Smooth transition effect

2. **Copy Action**
   - Click the copy button on any code block
   - Button turns green with a glow
   - Shows success feedback for 2 seconds
   - Code is copied to your clipboard

3. **In All Themes**
   - Dark theme: Gray to lighter gray gradient
   - Light theme: Subtle white gradient
   - Pink theme: Pink gradient
   - Pink 2 theme: Pink-red gradient

## Theme Switching - How To Use

### Quick Start
```
1. Click ⚙️ Settings button (top right)
2. Click "Appearance" section
3. Choose your theme
4. Done! Changes apply instantly
```

### Available Themes

#### 🌙 Dark (Default)
- **Best for:** Night usage, low-light environments
- **Colors:** Deep blue (#0b1020), slate gray text
- **Style:** Professional, easy on the eyes
- **Vibe:** Modern dark mode

#### ☀️ Light
- **Best for:** Daytime, bright environments
- **Colors:** Bright white (#f4f7fb), dark text
- **Style:** Clean, accessible
- **Vibe:** Fresh and bright

#### 💗 Pink
- **Best for:** Creative mood, night dark mode
- **Colors:** Deep magenta (#160d18), pink accents
- **Style:** Modern, stylish
- **Vibe:** Vibrant and energetic

#### 💕 Pink 2
- **Best for:** Creative mood, light variant
- **Colors:** Soft pink (#fff1f7), magenta accents
- **Style:** Elegant, gentle
- **Vibe:** Playful and modern

### Theme Features

✅ **Instant Switching**
- Themes apply immediately
- No page reload needed
- Smooth color transitions

✅ **Persistent Storage**
- Your theme choice is saved
- Returns to your chosen theme on next visit
- Works across browser sessions

✅ **Universal Adaptation**
- All UI elements update automatically:
  - Chat messages
  - Sidebar
  - Settings panel
  - Buttons and controls
  - Copy buttons
  - Scrollbars

## Tips & Tricks

### Theme Selection Tips
1. **For Programming**: Dark theme reduces eye strain
2. **For Documentation**: Light theme improves readability
3. **For Fun**: Switch to Pink or Pink 2 for a change
4. **Quick Switch**: Click Appearance → Choose theme
5. **No Side Effects**: Changing theme doesn't affect conversations

### Copy Button Tips
1. **Easy Access**: Button appears on hover over code
2. **Visual Feedback**: Green success indicator
3. **Always Works**: Paste after copying (Ctrl+V)
4. **Multiple Copies**: Can copy multiple code blocks
5. **All Browsers**: Works on Chrome, Firefox, Safari, Edge

## Troubleshooting

### Theme Not Saving?
- Clear browser cookies and try again
- Check if localStorage is enabled
- Try a different browser

### Copy Button Not Working?
- Make sure you're hovering over code block
- Try clicking exactly on the button
- Check browser console for errors
- Ensure clipboard permissions are granted

### Colors Look Off?
- Try refreshing the page
- Switch to another theme and back
- Check your monitor color settings
- Try a different browser
